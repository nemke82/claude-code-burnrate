● burnrate

Watch your Claude Code quota burn, live. One row above the prompt shows how fast your plan windows are filling, when they run out, and when your prompt cache was thrown away.

Reading the row

● burnrate 5h 62% +30%/h full in 1h 16m 7d 41% 98% cached
5h 62%
The plan window that matters most right now. Yellow at 70%, red at 90%.
+30%/h
The pace: how fast that window has been filling over the last half hour.
full in 1h 16m
Shown only when, at that pace, the window fills before it resets.
98% cached
How much of the last request the prompt cache served.
miss: model changed
A request wrote again what the previous one had cached, with an estimate of the tokens rewritten.

/burn for the detail

A pane with the session's totals, every cache miss and what is known about it, both plan windows with reset times and pace, and the last requests one by one.

Install

In Claude Code:

/plugin marketplace add nemke82/claude-code-burnrate
/plugin install burnrate@burnrate

Mods are early access. Start Claude Code with CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1, version 2.1.259 or later. The mod API may change between releases.

What it does not claim

  • No dollars. The only cost figure available is list price, which is not what a subscription or a custom contract pays. burnrate shows quota and tokens.
  • Miss sizes are estimates, marked with ~. The API reports how many tokens were read and written, not which ones.
  • A pause is not called an expiry. The mod cannot see which cache lifetime a request asked for, so it reports the pause and leaves the conclusion to you.
  • The pace is a projection, not a forecast. One heavy turn moves it, and the windows belong to your account, so other sessions move them too.
  • One point is not a trend. A window that moved a single point never raises a warning.

How it is built

Four hooks feed three pure modules: one detects cache misses, one works out the pace, one lays out the row and the pane as plain data. 44 tests cover them, including the row and pane mounted on every surface Claude Code draws to.

Source, tests and the demo scripts are on GitHub.
